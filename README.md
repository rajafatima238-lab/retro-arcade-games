# 🎮 Retro Arcade Games Collection

Welcome to the **Retro Arcade Games** repository! This is a collection of classic, fun, and interactive browser-based games built using modern web technologies. 

You can play these games directly in your browser without installing anything!

---

## 🕹️ Featured Games in this Collection

Here are the amazing games included in this project:

*   **🍎 Fruit Slusher (Fruit_slusher_Web_7):** Test your slicing skills in this fast-paced arcade game.
*   **🏓 Ping Pong (PingPong_Web_3):** The classic retro table tennis game. Beat the score!
*   **🐍 Snake Game (Snake_Web_1):** Control the snake, eat the food, and grow longer without hitting the walls.
*   **🚀 Space Arcade (SpaceArcade_web_6):** Protect the galaxy from incoming obstacles in this space-themed adventure.
*   **👾 Space Douge (Spacedouge_Web_2):** Dodge obstacles and survive as long as you can in deep space.
*   **⭐ Star Web (Star_Web_5):** A fun, celestial-themed challenge.
*   **🐢 Turtle Web (Turtle_Web_4):** Guide the turtle through obstacles.

1. Visit the Live Link (Coming Soon - We will update this in the next step!).

## 🛠️ Tech Stack Used

*   **HTML5:** For structured layout and game canvas elements.
*   **JavaScript (ES6):** For core game logic, physics, and rendering controls.
