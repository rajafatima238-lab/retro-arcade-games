## 🚀 How to Play

1. Visit the Live Link (1. Visit the [Live Link](https://rajafatima238-lab.github.io/retro-arcade-games/). - We will update this in the next step!).
2. Select your favorite game from the list.
3. Use your keyboard/mouse controls to play.

## 🛠️ Tech Stack Used

*   **HTML5:** For structured layout and game canvas elements.
*   **JavaScript (ES6):** For core game logic, physics, and rendering controls.
